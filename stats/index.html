One file per world. A second export of the same world replaces the older one (the date in the file name decides). Worlds created with the IW-Builder house kit also carry Stats: markers, charted per world below. To add them to your own world, start from the Stats Starter world (how to copy it).

Showing example data: three made-up worlds with invented numbers, in the same format as a real export. Load your own CSV files to replace them.

At a glance

Totals across the worlds ticked above. Player counts are added per world: IW does not say whether the same person played two worlds.

Turns played each day

One line per world. Hover for that day's players and credits, where IW reports them (older days list turns only).

How far they get

Share of each world's players whose longest game reached that turn. IW counts players, not games. A steep early drop is where new players leave.

Where players found it

Players by source. IW hides counts under 5; those show as a short faint bar labelled "under 5". A world with no row for a source shows a stub labelled "Not listed", so every color stays visible.

Part of the unaffiliated IW-Builder kit. How to read the numbers: a trigger at 0 usually means no game has reached it yet; compare it with the "How far they get" curve before calling it a bug. Trigger rows are counted per trigger ID, so a trigger rebuilt with a new ID appears twice.
