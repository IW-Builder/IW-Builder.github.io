# Tool usage and validation reference

Run commands from the package root. Python reads and writes package files explicitly as UTF-8.

## Validate an authored world

```sh
python tools/validate_iw_export.py WORLD.json --json
python tools/validate_iw_export.py WORLD.json --diff ORIGINAL.json --json
```

Install jsonschema for full schema coverage:

```sh
python -m pip install jsonschema
```

Without jsonschema, the validator reports schema-validation-unavailable and uses limited type/requiredness guards before checking references and lint. This is deliberately reduced coverage, not a substitute implementation of JSON Schema. Read the coverage object in JSON output. Exit status is 0 when no errors were found (warnings may remain), 1 for validation errors, and 2 for unreadable files/invalid JSON. No output certifies import or gameplay success.

## What it checks

- Full structural types/constraints when jsonschema is present.
- Explicit tracker, block, trigger, PC and skill references; duplicate IDs and wrapper/payload mismatches.
- Likely undeclared roots in Run Script, conditions, startup-choice expressions and <<...>> templates throughout the export. Declared tracker variableName values, script locals, $game and $player are accounted for. Video-context placeholders are reported separately where applicable.
- Likely borrowed operators and block syntax outside quoted literals/comments, and common string-plus concatenation mistakes.
- Recognizable library editing placeholders. Generic comments and intentional runtime notation should not be removed just to silence warnings.
- Searchable content-substitution markers, reported as review warnings rather than import errors; reconcile them with the separate Authoring report.
- A trailing newline in the actual input file.
- In --diff mode, added/removed/changed object IDs, ordering changes and changed field paths. Long string values are summarized with length and hash; the files remain the authoritative complete values.

## Limitations and warning review

Static lint is heuristic. It does not parse all PawScript, resolve arbitrary dynamic paths, model control flow, evaluate templates, or validate the full formatSchema language. Script locals are recognized lexically; declaration order and every branch scope are not proven. A root warning can expose a missing tracker or a context-specific engine variable; investigate it rather than inventing a tracker automatically. New syntax can produce false positives.

The module library deliberately contains authoring slots and alternative dependency sets, so placeholder/root warnings there are expected until the selected modules are adapted. Finished worlds should have no unexplained warnings. A native YAML path can be semantically wrong even when all static checks pass; compare it with the intended runtime structure.

A diff proves what changed, not whether those changes are authorized or correct. Reordered arrays can generate positional changes while the object-ID summary remains easier to read. The tool does not execute scripts or verify runtime behavior.

## Portable data and full-content reports

`data_bank.py` exports selected native content or the entire world into a readable text bank with authoritative JSON and an integrity hash. It also packs/unpacks editable bank JSON and restores unchanged complete-world reports. It does not automatically integrate entries or infer their dependencies. See [Portable-Banks.md](../reference/Portable-Banks.md) for commands, tags, bundles, PC/NPC conversion and preservation rules. No third-party dependencies are required. Output files are never silently overwritten.

## Maintainer commands

These are repository maintenance tasks, not requirements for authoring worlds:

```sh
python tools/test_validator.py
python tools/test_data_bank.py
python tools/test_distribution.py
python tools/test_engineering.py
python tools/test_native_compat.py
python tools/test_story_export.py
python tools/check_package.py
python tools/build_distribution.py
```

`build_distribution.py` uses its own location in `/tools` to find the repository, so it needs no arguments and works from any working directory. It uses only Python's standard library. Run validation before building when publishing changed worlds or tools.

The builder updates visible EOF markers in AI-facing Markdown documents, generates `index.html` from `Authoring-Prompt.md`, synchronizes the checker's embedded validator/schema, writes the combined chat TXT files and `chat/sources.json`, generates `llms.txt` and the folder index pages from the descriptions table in `build_distribution.py`, then hashes the finished files into root `manifest.json`. It does not produce a separate `prompt.txt`, run validation or rebuild ZIP archives. Repackage `full-package.zip` after the build when distributing a new archive.

Required sources are checked before output begins; a missing source or checker embedding stops the build with an error. Repeated builds with unchanged inputs preserve output bytes and the manifest timestamp. A write failure can leave partial outputs; fix it and rerun before publishing.

`IW-Tools.txt` has an explicit authoring-tool list: this usage guide, the Story-Tools and Engineering-Tools guides, validator, static checks, JSON schema, data-bank utility, import audit, story-export tool, browser harness and plot compiler. Builders, regression tests and package reports remain in the repository but are omitted from that model-facing bundle. Human READMEs are also omitted from combined technical packages. No model needs the distribution builder to author a world.

The root manifest records repository-relative paths, byte lengths and SHA-256 hashes. It covers the authoring sources and supported files under reference, library, examples, tools, chat and checker, plus the homepage and root guide/template/license. It excludes itself, ZIP archives, sample histories, hidden files and caches. It is separate from the files it hashes to avoid circular dependencies. Hash original bytes, never a browser's rendered/extracted text. A mismatch may mean the manifest is stale; investigate apparent missing content without treating every mismatch as damage. A match establishes the recorded bytes, not freshness or runtime correctness.

EOF markers are added only to AI-facing Markdown and the generated chat documents. They are not added to JSON, scripts, the native default Evaluation text or other directly reusable content. They are documentation boundaries, not world instructions to copy into a story.

## Import audit and story exports

Use `python tools/import_audit.py source.json imported.json` for possible tracker reminting, stale references and a loss-aware structural diff. It never rewrites the worlds. Full schema coverage depends on jsonschema; source hashes and comparison do not.

Use `python tools/story_export.py plan story.txt --world world.json --session NAME --branch NAME` to propose a layout. After source review, `build plan.json --output NEW_DIRECTORY` extracts/merges it; `verify NEW_DIRECTORY` checks manifest hashes. These subcommands follow `python tools/story_export.py`. It requires a new output directory and explicit reviewed boundaries/session/branch declarations. It preserves raw source and tracker strings, rejects conflicts/gaps, and never selects by timestamps. See [Story tools](../reference/Story-Tools.md) for partial histories and ambiguous delimiters.

Run all maintained regression checks with `python -m unittest discover -s tools -p "test_*.py"`. These are local tool checks, not IW execution.

See [Engineering tools](../reference/Engineering-Tools.md) for `iw_browser.py` setup, capture/export/recovery contracts and `plot_compile.py` plan syntax. Browser support is optional and uses `requirements-browser.txt`. No tool here submits a game turn, imports a world or publishes content. # Story extraction and import diagnostics

These local tools operate on files, not the live game. They do not infer hidden character records, run PawScript or certify narrative consistency.

## Compare a source world with its native re-export

Run:

```sh
python tools/import_audit.py source.json imported.json
```

The report includes source hashes, complete structural differences, possible tracker-ID changes and references still pointing at removed tracker targets. Possible identity changes require a unique Name/variable-handle candidate; ambiguity is reported, never automatically repaired. Array changes remain visible even when positional reordering makes them noisy. No input is modified.

The validator supports native string turn thresholds, the editor-recognized first-action/Other Character effects, and the verified turn_number root. Other Character mutation remains runtime-unverified. Exact Scenario mismatches are errors when a registry is present; an absent registry produces migration guidance rather than pretending a legacy import cannot populate it. Non-alphanumeric tracker IDs produce an import-risk advisory. Findings identify the owning tracker/trigger Name where available; JSON paths remain technical coordinates.

## Extract story text without silently resolving ambiguity

Run:

```sh
python tools/story_export.py plan story.txt --world world.json --session my-session --branch main > plan.json
```

The plan proposes turn, section and tracker line ranges using the world's tracker Names. Review the actual source at those ranges, correct any boundary mistaken for prose/data, resolve reviewIssues, and set reviewed to true. A human or an AI with access to the source can perform this review. This is a data-review requirement, not a request to rerun the story. Duplicate tracker Names cannot be safely represented as a Name-keyed state map; resolve that ambiguity before extraction.

Native story text has no escaping contract for headings. An embedded marker that looks exactly like a real turn or section can be indistinguishable by syntax alone. The source hash locks a plan to the reviewed bytes; review is an operator assertion, not an authenticated platform identity or a proof of automatic parsing correctness. Unknown prose headings are retained, and detected duplicate/out-of-order known boundaries are rejected.

Then run:

```sh
python tools/story_export.py build plan.json --output new-extraction
python tools/story_export.py verify new-extraction
```

Output includes original source bytes, reviewed plans, story.json and a SHA-256 manifest. Tracker values remain raw text, preserving nested YAML and multiline content rather than inventing typed structure. Blank separators may remain in raw value spans. Section text and original bytes provide the complete source representation. Line ranges are one-based and inclusive.

The output path must be new. Publication uses a fresh sibling staging directory, validates its hashes and renames the completed directory into place. Existing output is never reused or deleted, preventing stale files from masquerading as new state. Read only manifest-listed files; verify checks their hashes and ignores unrelated files.

## Merge only an explicitly selected history

Supply multiple reviewed plans to build. Every plan must declare the same nonempty session and branch. Neither title, player Name, timestamp nor overlap proves identity. Identical overlapping turn content and extraction can deduplicate, retaining all source provenance. Any conflicting overlap is rejected, independent of file modification time or input order.

Select a single coherent branch/revision before building conflicting history; the tool offers no latest-file winner and does not combine downstream turns from divergent branches automatically. Complete histories require turn one and no gaps. --partial permits a contiguous later range and labels it partial; it does not permit holes or silently promote partial history to complete.

The tool is a conservative IW-Builder implementation. It does not patch or certify the separate external parser. Standalone live-browser capture and recovery remain separate roadmap items.

# Browser capture and plot compilation

These are local authoring tools, not platform APIs. They never submit a turn or publish a world. See [Story tools](Story-Tools.md) for export parsing and import comparison.

## Standalone browser harness

`tools/iw_browser.py` uses an optional Playwright dependency and a dedicated local Chromium profile. The in-app browser's login is a separate session. Authenticated standalone connection, rendered-page capture and refresh-verified editor export were verified on 2026-10-23. Exported content matched the preserved original and passed structural validation. This establishes the observed capture/export workflow, not imports, gameplay automation, interrupted-turn recovery or server persistence. A command-runner sandbox may block local debugging sockets even when the browser is running; in that environment, run the harness from your own terminal.

Install into a local virtual environment from the kit root:

```text
python -m venv .venv
.venv/Scripts/python -m pip install -r tools/requirements-browser.txt
.venv/Scripts/python -m playwright install chromium
.venv/Scripts/python tools/iw_browser.py launch
```

Log in directly in the dedicated browser. Keep its launcher terminal open. The profile defaults to `.iw-builder-browser` under your home directory; keep it private. Debugging binds to loopback. The launcher opens a visible interactive browser for login. On non-Windows systems use `.venv/bin/python`.

In a second terminal:

```text
.venv/Scripts/python tools/iw_browser.py status
.venv/Scripts/python tools/iw_browser.py capture captures/before --tab 0
.venv/Scripts/python tools/iw_browser.py export-current exports/world.json --tab 0 --expected-title "My World"
.venv/Scripts/python tools/iw_browser.py inspect captures/before
```

`status` lists only Infinite Worlds hostnames. Multiple tabs require an explicit index. Open the intended editor/raw panel yourself and finish any import/rebuild before export. The exact title check concerns the raw buffer; it is not authentication or a server identity check.

Export preserves the current raw buffer as `world.json.before.json`, then temporarily replaces only that raw text with a unique invalid-JSON marker and clicks Refresh raw JSON. Do not interact with the editor during this operation. It never clicks Import or Save. It requires the marker to be replaced by valid JSON of the expected title; unchanged final content is valid when regeneration was observed. A timeout is failure, not permission to reuse old raw text. A successful export has a hash/freshness receipt. This establishes editor regeneration, not server persistence or complete live state.

After failure, the original raw text is restored only if the buffer still contains the tool's marker. If disconnected, the backup remains available; manually restore it after reconnecting if needed. A failed receipt write can leave the exported JSON without a receipt: treat it as incomplete and inspect it, then use a new output path. Existing export/backup/receipt names are never overwritten.

Capture writes page text, accessibility text, metadata and hashes into a new directory. Partial capture staging is removed on failure; earlier captures remain untouched. `inspect` verifies listed files offline. Closed panels, historical prompts and live character records are outside its scope. Captures can contain story material; review before sharing.

Recovery is observational: reconnect, run status, choose the intended tab and capture again. Check retained history and controls before deciding whether any action needs retrying. This harness never reloads, regenerates or resubmits a turn automatically. A future unattended gameplay runner needs a separate supported persistence/completion signal; streamed narration is insufficient.

## Literal-Scenario plot compiler

`tools/plot_compile.py` accepts a deliberately bounded plan: title and nodes; each node has an internal lowercase identifier, a user-facing Name, a literal Scenario, optional all-of prerequisites and a nonnegative integer award. It builds a fresh world, never modifies an existing one. See [example plan](../tools/example-plot-plan.json).

```text
python tools/plot_compile.py tools/example-plot-plan.json
python tools/plot_compile.py tools/example-plot-plan.json --output new-world.json
```

Without output, it reports dependency order, roots, structurally reachable nodes and shared Scenarios. With output, it also validates and writes a new world; existing files are refused. Full schema checks need `jsonschema`; otherwise the report explicitly identifies reduced coverage.

Generation puts prerequisite triggers before their dependents. A single script guards both completion and award and commits them together, allowing retry when a script has not completed. The resulting world uses literal Scenarios and a script-owned Plot progress tracker. Two eligible nodes sharing a Scenario may both complete in one turn; no hidden priority or fairness rule is implied. Later narration sees committed state according to platform timing; the compiler does not rewrite narration retrospectively.

Unknown prerequisites, cycles, duplicate identifiers, dynamic Scenario templates and unsupported plan fields are rejected. This compiler supports prerequisite DAGs, not arbitrary cyclic plots, mutually exclusive branches or all possible IW worlds. Independent nodes retain author order. It does not infer events from prose or prove that the AI will recognize a Scenario, that a scene is achievable, or that every player's route is possible. Connectivity is not narrative satisfiability. The generated composition is structurally checked, not live-certified.

#!/usr/bin/env python3
"""Validate observed IW export structure, references, and evidence gaps.

Usage: python validate_iw_export.py WORLD.json [--schema SCHEMA.json] [--json]
Exit codes: 0 = no errors (warnings permitted), 1 = validation errors,
2 = input failure. jsonschema is optional; reduced coverage is reported when absent. Never executes PawScript.
"""
from __future__ import annotations
import argparse
import json
import re
import sys
from pathlib import Path
from static_checks import lint, basic_errors, edit_diff
try:
    from jsonschema import Draft202012Validator
except ImportError:
    Draft202012Validator = None

def pointer(parts):
    return '/'+'/'.join(str(p).replace('~','~0').replace('/','~1') for p in parts) if parts else '/'

def validate(doc, schema):
    findings=[]
    def add(level,code,path,message):
        findings.append({'severity':level,'code':code,'path':path,'message':message})
    if Draft202012Validator is not None:
        Draft202012Validator.check_schema(schema)
        for e in sorted(Draft202012Validator(schema).iter_errors(doc),key=lambda e:str(list(e.path))):
            add('error','structure',pointer(e.path),e.message)
    else:
        add('warning','schema-validation-unavailable','/','jsonschema is unavailable. Full JSON Schema validation was NOT run; limited type guards, references and static lint remain available.')
        findings.extend(basic_errors(doc,schema))
    if not isinstance(doc,dict): return findings
    if any(f['severity']=='error' for f in findings): return findings
    defs=schema.get('$defs',{})

    def resolved(s,value):
        if '$ref' in s:
            key=s['$ref'].rsplit('/',1)[-1]
            if key=='conditionNode' and isinstance(value,dict):
                if value.get('category')=='logic': return defs[key]['anyOf'][0]
                if value.get('category')=='condition': return resolved(defs['conditionLeaf'],value)
                return {}
            return resolved(defs[key],value)
        tag=s.get('x-discriminator')
        if tag and isinstance(value,dict):
            val=value.get(tag)
            prefix='effect' if tag=='type' and s is defs.get('effect') else 'condition'
            return defs.get(prefix+'_'+str(val),{})
        if 'anyOf' in s:
            matches=[x for x in s['anyOf'] if not basic_errors(value,x,schema)]
            return resolved(matches[0],value) if matches else {}
        return s

    def audit(value,s,path):
        s=resolved(s,value)
        observed=s.get('x-observedValues')
        if observed is not None and value not in observed:
            add('warning','unobserved-value',path,'Value is outside observed vocabulary; not declared invalid: '+repr(value))
        if isinstance(value,dict) and s.get('type')=='object':
            props=s.get('properties',{})
            for k,v in value.items():
                p=path.rstrip('/')+'/'+str(k).replace('~','~0').replace('/','~1')
                if k not in props:
                    extra=s.get('additionalProperties')
                    if isinstance(extra,dict): audit(v,extra,p)
                    else: add('warning','unobserved-field',p,'Field has no characterized schema at this location.')
                else: audit(v,props[k],p)
        elif isinstance(value,list) and s.get('type')=='array':
            for i,v in enumerate(value): audit(v,s.get('items',{}),path.rstrip('/')+'/'+str(i))
    audit(doc,schema,'/')
    if doc.get('schemaVersion') not in schema.get('x-observedSchemaVersions',[]):
        add('warning','schema-version','/schemaVersion','Version missing or outside observed versions; profile coverage is not established.')

    tables={}
    for field,idkey in [('trackedItems','id'),('triggerEvents','id'),('possibleCharacters','characterId'),('instructionBlocks','id'),('loreBookEntries','id'),('NPCs','id')]:
        tables[field]={}
        for i,o in enumerate(doc.get(field,[]) if isinstance(doc.get(field,[]),list) else []):
            if not isinstance(o,dict): continue
            p='/'+field+'/'+str(i)+'/'+idkey
            ident=o.get(idkey)
            if not isinstance(ident,str) or not ident:
                add('warning','missing-id',p,'No usable identifier; requiredness is not established, but references cannot resolve.');continue
            if ident in tables[field]: add('error','duplicate-id',p,'Identifier is duplicated within '+field+': '+ident)
            tables[field][ident]=o
    def ref(ident,namespace,path,condition=False):
        if not isinstance(ident,str): return
        if ident in tables[namespace]: return
        if condition and ident in schema.get('x-observedConditionExternalReferences',[]):
            if ident=='skill_player_skill_1' and 'Player - Skill 1' not in doc.get('skills',[]):
                add('warning','skill-binding',path,'Observed skill variable used without its sample skill name; general binding rule is unknown.')
            return
        if condition and ident.startswith('skill_'):
            add('warning','unknown-skill-reference',path,'Unobserved built-in skill reference; normalization and binding not verified.');return
        add('error','unresolved-reference',path,'No declared '+namespace+' target: '+ident)

    seen_node_ids={}
    def node_id(n,p):
        ident=n.get('id')
        if not isinstance(ident,str) or not ident:
            add('warning','missing-node-id',p+'/id','Condition/effect node has no usable ID; importer requirements unknown.')
        elif ident in seen_node_ids: add('warning','duplicate-node-id',p+'/id','Node ID is reused at '+seen_node_ids[ident])
        else: seen_node_ids[ident]=p
    def compare_wrapper(n,d,p):
        for k in ('trackedItemID','inequality'):
            if k in n and k in d and n[k]!=d[k]:
                add('error','wrapper-payload-mismatch',p+'/'+k,'Wrapper and payload disagree; runtime precedence unknown.')
    def conditions(nodes,p,start_enabled=False):
        for i,n in enumerate(nodes if isinstance(nodes,list) else []):
            q=p+'/'+str(i)
            if not isinstance(n,dict): continue
            node_id(n,q)
            category=n.get('category')
            if category=='logic':
                if n.get('operator') not in ['and','or','none_of']: add('warning','unknown-logic',q+'/operator','Unobserved operator.')
                if 'data' not in n: add('warning','missing-payload',q+'/data','Logic group has no child list.')
                conditions(n.get('data',[]), q+'/data', start_enabled);continue
            if category!='condition': add('warning','unclassified-condition',q+'/category','Missing or unobserved category.')
            t=n.get('type'); d=n.get('data')
            if start_enabled and t in ('triggerOnTurn', 'triggerOnEvent'):
                label = (
                    'Minimum-turn' if t == 'triggerOnTurn'
                    else 'Scenario'
                )
                add('warning', 'start-incompatible-condition', q, label + 
                    ' condition combined with Start of Game. Condition ignored; does not gate execution. Use separate startup trigger and leave Start off here.'
                )
            if t not in defs['conditionLeaf']['x-knownDiscriminators']:
                add('warning','unknown-condition-type',q+'/type','Missing or unobserved condition type: '+repr(t));continue
            if 'data' not in n: add('warning','missing-payload',q+'/data','No condition payload observed.');continue
            if isinstance(d,dict): compare_wrapper(n,d,q)
            if t=='triggerOnCharacter' and isinstance(d,list):
                for j,x in enumerate(d): ref(x,'possibleCharacters',q+'/data/'+str(j))
            elif t=='triggerOnTrackedItem' and isinstance(d,dict):
                ref(d.get('trackedItemID'),'trackedItems',q+'/data/trackedItemID',condition=True)
                if not isinstance(d.get('textComparison'),str) or not d['textComparison'].strip():
                    add('warning','missing-native-comparator',q+'/data/textComparison','Native tracker comparisons retain textComparison even for numeric targets. Missing/blank values can be omitted or inactive on import; preserve the native nonempty field.')
            elif t in ['triggerPrereqs','triggerBlockers'] and isinstance(d,dict):
                key='prereqs' if t=='triggerPrereqs' else 'blockers'
                for j,x in enumerate(d.get(key,[]) if isinstance(d.get(key,[]),list) else []): ref(x,'triggerEvents',q+'/data/'+key+'/'+str(j))
            elif t=='triggerOnEvent' and isinstance(d,str) and d not in doc.get('conditions',[]):
                if 'conditions' not in doc:
                    add('warning','missing-scenario-registry',q+'/data','No explicit Scenario registry. Legacy imports can populate one; inspect the native re-export and selected binding before use.')
                else:
                    add('error','unlisted-situation',q+'/data','Scenario has no exact registry binding; case, spacing and punctuation must match a declared Scenario.')
            elif t=='triggerOnPawScript': add('warning','unverified-expression',q+'/data','Expression is stored text; not parsed or executed.')
    for i,t in enumerate(doc.get('triggerEvents',[]) if isinstance(doc.get('triggerEvents',[]),list) else []):
        if not isinstance(t,dict): continue
        p='/triggerEvents/'+str(i)
        if not t.get('triggerOnStartOfGame') and not t.get('triggerConditions'):
            add('warning','saved-inactive-trigger',p,'Valid saved trigger with no ordinary automatic firing conditions; explicit random dispatch may still call it.')
        numeric_writes={}
        flat_req=set();flat_block=set()
        for n in t.get('triggerConditions',[]):
            if isinstance(n,dict) and n.get('category')=='condition' and isinstance(n.get('data'),dict):
                data=n['data'];scope=data.get('firedThisTurn',False)
                if n.get('type')=='triggerPrereqs':flat_req.update((x,scope) for x in data.get('prereqs',[]))
                if n.get('type')=='triggerBlockers':flat_block.update((x,scope) for x in data.get('blockers',[]))
        if flat_req & flat_block:add('warning','dependency-editor-conflict',p,'Flat AND prerequisites and blockers conflict within the same scope.')
        for e in t.get('triggerEffects',[]):
            if isinstance(e,dict) and e.get('type')=='effectSetTrackedItemValue' and isinstance(e.get('data'),dict):
                ident=e['data'].get('trackedItemID')
                if tables['trackedItems'].get(ident,{}).get('dataType')=='number':numeric_writes[ident]=numeric_writes.get(ident,0)+1
        for ident,count in numeric_writes.items():

"""Conservative static diagnostics. Not a PawScript parser or JSON Schema implementation."""
from __future__ import annotations
import json,re,hashlib

SYSTEM_ROOTS={'game','player','turn_number'}
ROOT=re.compile(r'\$([A-Za-z_][A-Za-z_0-9]*)')
PLACEHOLDERS=re.compile(r'\[(?:LIST [A-Z _]+|DESCRIBE [A-Z _]+|Author Style|title|blurb)\]|<#\s*(?:time period|Copy in|DESCRIBE|LIST |VARIABLE BLOCK)[\s\S]*?#>',re.I)

def escaped(k):return str(k).replace('~','~0').replace('/','~1')
def walk(value,path=''):
    if isinstance(value,dict):
        for k,v in value.items():yield from walk(v,path+'/'+escaped(k))
    elif isinstance(value,list):
        for i,v in enumerate(value):yield from walk(v,path+'/'+str(i))
    elif isinstance(value,str):yield path,value

def mask_literals(code):
    """Mask single/double quoted strings and # comments without changing line positions."""
    return re.sub(r'"(?:\\.|[^"\\])*"|\'(?:\\.|[^\'\\])*\'|\#[^\n]*',lambda m:''.join('\n' if c=='\n' else ' ' for c in m.group()),code)

def templates(text):
    """Extract <<...>> while respecting quoted >>; unmatched delimiters are not parsed."""
    text=re.sub(r'<#[\s\S]*?#>',lambda m:' '*len(m.group()),text)
    pos=0
    while True:
        start=text.find('<<',pos)
        if start<0:return
        i=start+2;quote=None;escape=False
        while i<len(text):
            ch=text[i]
            if quote:
                if escape:escape=False
                elif ch=='\\':escape=True
                elif ch==quote:quote=None
            elif ch in ['"',"'"]:quote=ch
            elif text.startswith('>>',i):
                yield text[start+2:i];pos=i+2;break
            i+=1
        else:return

def lint(doc):
    findings=[]
    def add(code,path,message):findings.append(dict(severity='warning',code=code,path=path or '/',message=message))
    declared={x.get('variableName') for x in doc.get('trackedItems',[]) if isinstance(x,dict) and isinstance(x.get('variableName'),str)}
    snippets=[];script_paths=set()
    def nodes(x,path=''):
        if isinstance(x,dict):
            typ=x.get('type')
            if typ in ['effectRunScript','triggerOnPawScript','triggerOnRandomChance'] and isinstance(x.get('data'),str):
                sp=path+'/data';snippets.append((sp,x['data'],typ=='effectRunScript'));script_paths.add(sp)
            for k,v in x.items():
                kp=path+'/'+escaped(k)
                if k in ['initialPCValueChoicesScript','initialValueChoicesScript'] and isinstance(v,str) and v.strip():snippets.append((kp,v,False));script_paths.add(kp)
                nodes(v,kp)
        elif isinstance(x,list):

    nodes(doc)
    for path,text in walk(doc):
        markers=sorted(set(re.findall(r'<#\s*(?:END_)?(REPLACE\d+)\b[\s\S]*?#>',text)))
        if markers:add('content-substitution',path,'Intentional content substitution marker(s): '+', '.join(markers)+'. Review the separate Authoring report and intended behavior; these are not import errors.')
        if PLACEHOLDERS.search(text):add('authoring-placeholder',path,'Possible unresolved library editing slot. Review; intentional runtime notation and ordinary comments need not be removed.')
        if path not in script_paths:
            for expr in templates(text):snippets.append((path,expr,False))
    for path,code,is_script in snippets:
        clean=mask_literals(code)
        locals_=set(re.findall(r'\b(?:set|for\s+each)\s+\$([A-Za-z_][A-Za-z_0-9]*)',clean)) if is_script else set()
        unknown=set(ROOT.findall(clean))-declared-SYSTEM_ROOTS-locals_
        for name in sorted(unknown):
            if path.startswith('/videoPromptInstructions') and name in ['videoDuration','videoStyle']:
                add('context-root-unverified',path,'Video-context $'+name+' is not a declared tracker; availability in this field is not established by this kit.')
            else:add('unknown-script-root',path,'$'+name+' is not a declared tracker variableName, script local, or known system root. Check missing dependencies; lint is not a full language/context parser.')

        # Identify quoted-string + operand without looking inside literal text.
        lit=re.compile(r'"(?:\\.|[^"\\])*"|\'(?:\\.|[^\'\\])*\'')
        for m in lit.finditer(code):
            if re.match(r'\s*\+\s*(?:\$|["\'])',clean[m.end():]) or re.search(r'\$[\w.()]+\s*\+\s*$',clean[:m.start()]):
                add('string-plus',path,'Possible string concatenation with +; use &. Review this heuristic warning.');break
    findings.extend(pattern_advisories(doc))

def basic_errors(value,schema,root=None,path=''):
    """A limited type/requiredness guard used without jsonschema. Coverage is explicitly reduced."""
    root=root or schema;out=[]
    if not isinstance(schema,dict):return out
    if '$ref' in schema:
        target=root
        for part in schema['$ref'].lstrip('#/').split('/'):target=target.get(part,{})
        return basic_errors(value,target,root,path)
    if schema.get('x-discriminator') and isinstance(value,dict):
        prefix='effect' if str(value.get('type','')).startswith('effect') else 'condition'
        target=root.get('$defs',{}).get(prefix+'_'+str(value.get('type')))
        if target:return basic_errors(value,target,root,path)
    if 'anyOf' in schema:
        branches=[basic_errors(value,s,root,path) for s in schema['anyOf']]
        if any(not x for x in branches):return []
        return [dict(severity='error',code='basic-structure',path=path or '/',message='Value does not match the checked type alternatives (reduced validation).')]
    if 'not' in schema and not basic_errors(value,schema['not'],root,path):
        return [dict(severity='error',code='basic-structure',path=path or '/',message='Excluded alternative (reduced validation).')]
    for sub in schema.get('allOf',[]):out+=basic_errors(value,sub,root,path)
    typ=schema.get('type')
    types={'object':isinstance(value,dict),'array':isinstance(value,list),'string':isinstance(value,str),'boolean':isinstance(value,bool),'integer':isinstance(value,int) and not isinstance(value,bool),'number':isinstance(value,(int,float)) and not isinstance(value,bool),'null':value is None}
    def error(msg):out.append(dict(severity='error',code='basic-structure',path=path or '/',message=msg))
    if typ and not any(types.get(t,False) for t in (typ if isinstance(typ,list) else [typ])):error('Expected '+str(typ));return out
    if 'const'in schema and value!=schema['const']:error('Constant value mismatch.')
    if 'enum'in schema and value not in schema['enum']:error('Value is outside the declared enum.')
    if isinstance(value,(int,float)) and not isinstance(value,bool):
        if 'minimum'in schema and value<schema['minimum']:error('Below minimum.')
        if 'maximum'in schema and value>schema['maximum']:error('Above maximum.')
    if isinstance(value,dict):
        for k in schema.get('required',[]):
            if k not in value:error('Missing required field '+k)
        for k,v in value.items():
            sub=schema.get('properties',{}).get(k,schema.get('additionalProperties',{}))
            if isinstance(sub,dict):out+=basic_errors(v,sub,root,path+'/'+escaped(k))
    if isinstance(value,list):
        if len(value)<schema.get('minItems',0):error('Too few items.')
        if 'maxItems'in schema and len(value)>schema['maxItems']:error('Too many items.')
        for i,v in enumerate(value):out+=basic_errors(v,schema.get('items',{}),root,path+'/'+str(i))
    return out

def edit_diff(old,new):
    changes=[]
    def brief(v):
        if isinstance(v,str) and len(v)>160:return {'preview':v[:160],'characters':len(v),'sha256':hashlib.sha256(v.encode('utf-8')).hexdigest()}
        return v
    def compare(a,b,path=''):
        if type(a)!=type(b):changes.append({'path':path or '/','change':'type/value','before':brief(a),'after':brief(b)});return
        if isinstance(a,dict):
            for k in sorted(set(a)|set(b)):
                q=path+'/'+escaped(k)
                if k not in a:changes.append({'path':q,'change':'added','after':brief(b[k])})
                elif k not in b:changes.append({'path':q,'change':'removed','before':brief(a[k])})
                else:compare(a[k],b[k],q)
        elif isinstance(a,list):
            if a!=b:
                for i in range(max(len(a),len(b))):
                    q=path+'/'+str(i)
                    if i>=len(a):changes.append({'path':q,'change':'added','after':brief(b[i])})
                    elif i>=len(b):changes.append({'path':q,'change':'removed','before':brief(a[i])})
                    else:compare(a[i],b[i],q)
        elif a!=b:changes.append({'path':path,'change':'changed','before':brief(a),'after':brief(b)})
    compare(old,new)
    objects={}
    for field,idkey in [('trackedItems','id'),('triggerEvents','id'),('possibleCharacters','characterId'),('instructionBlocks','id'),('loreBookEntries','id'),('NPCs','id')]:
        def lookup(w):return {x[idkey]:x for x in w.get(field,[]) if isinstance(x,dict) and isinstance(x.get(idkey),str)} if isinstance(w,dict) and isinstance(w.get(field,[]),list) else {}
        a,b=lookup(old),lookup(new)
        objects[field]={'added':sorted(b.keys()-a.keys()),'removed':sorted(a.keys()-b.keys()),'changed':sorted(k for k in a.keys()&b.keys() if a[k]!=b[k]),'orderChanged':list(a)!=list(b)}
    return {'objects':objects,'changes':changes,'note':'Reports differences, not whether they are authorized. Array indices are positional; object summaries match IDs.'}


def pattern_advisories(doc):
    """Narrow review prompts, never proof of a missing guard or invalid runtime behavior."""
    out=[]
    def add(code,path,message):out.append(dict(severity='warning',code=code,path=path,message=message))
    triggers=doc.get('triggerEvents',[])
    if not isinstance(triggers,list):return out
    for i,t in enumerate(triggers):
        if not isinstance(t,dict):continue
        effects=t.get('triggerEffects',[])
        if not isinstance(effects,list):continue
        for j,e in enumerate(effects):
            if not isinstance(e,dict):continue
            typ=e.get('type');d=e.get('data');path=f'/triggerEvents/{i}/triggerEffects/{j}/data'
            if typ=='effectRunScript' and isinstance(d,str):
                clean=mask_literals(d)
                if t.get('canTriggerMoreThanOnce') and re.search(r'^\s*\$[\w.]+\s*\+=',clean,re.M):
                    add('review-repeat-accumulation',path,'Repeatable script accumulates a value. Review its completion/consumption guard if this is a one-time reward; recurring counters are valid. No missing guard is inferred.')
                if any(isinstance(x,dict) and x.get('type')=='effectRunScript' for x in effects[:j]):
                    add('review-script-boundary',path,'Earlier Run Script effects have separate locals and rollback. Keep an accepted-state commit and its completion flag together if they must succeed together.')
            if typ=='effectPresentChoice' and isinstance(d,dict):
                if d.get('selectionMode')=='multiple':
                    add('review-choice-storage',path,'Multiple selections can be newline-delimited text. Validate the intended domain and representation before treating this value as a YAML list.')
                if isinstance(d.get('choices'),str) and '<<' in d['choices']:
                    add('review-choice-domain',path,'Choices are computed. Review blank/duplicate values, fallback and membership checks at the point where the answer is consumed; display choices alone do not validate all write paths.')
    draws=[]
    for path,text in walk(doc):
        if not any(k in path for k in ('/content','/instructions','/descriptionRequest')):continue
        for expr in templates(text):
            if re.search(r'\b(?:random|random_between|dice_roll)\s*\(',mask_literals(expr)):draws.append(path)
    if len(draws)>1:
        add('review-independent-random',draws[0],'Several rendered expressions draw independently. Cache a single choice in a tracker when these consumers must agree; independent draws are otherwise valid.')
    return out

"""Portable IW Data banks: readable TXT with an authoritative JSON payload.

No dependencies. Does not execute IW/PawScript or automatically integrate worlds.
"""
from pathlib import Path
from decimal import Decimal
import argparse
import hashlib
import json
import re
import sys
import uuid

FORMAT = 'iw-data-bank'
BEGIN = '<!-- BEGIN IW DATA BANK -->'
END = '<!-- END IW DATA BANK -->'
COLLECTIONS = {'NPCs':'npc', 'possibleCharacters':'pc', 'trackedItems':'tracker',
               'triggerEvents':'trigger', 'instructionBlocks':'block', 'loreBookEntries':'keyword'}

def pairs(items):
    result = {}
    for k,v in items:
        if k in result: raise ValueError('Duplicate JSON key: '+k)
        result[k] = v
    return result

def invalid_number(value): raise ValueError('Not a finite JSON number: '+value)

def loads(text):
    return json.loads(text, object_pairs_hook=pairs, parse_float=Decimal,
                      parse_constant=invalid_number)

def dumps(value, depth=0, canonical=False):
    """Preserve decimal precision and JSON value types without a float conversion."""
    if isinstance(value, Decimal):
        if not value.is_finite(): raise ValueError('Non-finite number')
        text = str(value)
        return text if any(c in text for c in '.eE') else text+'.0'
    if isinstance(value, (dict,list)):
        is_dict = isinstance(value,dict)
        opening,closing = ('{','}') if is_dict else ('[',']')
        if not value: return opening+closing
        if is_dict:
            if not all(isinstance(k,str) for k in value): raise ValueError('JSON keys must be strings')
            keys = sorted(value) if canonical else value
            parts = [json.dumps(k,ensure_ascii=True)+(': ' if not canonical else ':')+dumps(value[k],depth+1,canonical) for k in keys]
        else: parts = [dumps(v,depth+1,canonical) for v in value]
        if canonical: return opening+','.join(parts)+closing
        return opening+'\n'+'  '*(depth+1)+(',\n'+'  '*(depth+1)).join(parts)+'\n'+'  '*depth+closing
    return json.dumps(value,ensure_ascii=True,allow_nan=False)

def digest(value): return hashlib.sha256(dumps(value,canonical=True).encode('utf-8')).hexdigest()
def escape(key): return key.replace('~','~0').replace('/','~1')

def tokens(pointer):
    if not pointer.startswith('/'): raise ValueError('Use a JSON Pointer beginning with /')
    if re.search(r'~(?![01])',pointer): raise ValueError('Invalid JSON Pointer escape')
    return [s.replace('~1','/').replace('~0','~') for s in pointer[1:].split('/')]

def get(doc,pointer):
    value = doc
    for token in tokens(pointer):
        if isinstance(value,list):
            if not re.fullmatch(r'0|[1-9][0-9]*',token): raise ValueError('Invalid list index in '+pointer)
            value=value[int(token)]
        elif isinstance(value,dict): value=value[token]
        else: raise ValueError('Path traverses a scalar: '+pointer)
    return value

def validate(bank):
    if not isinstance(bank,dict) or bank.get('format')!=FORMAT or type(bank.get('version')) is not int or bank['version']!=1:
        raise ValueError('Expected an iw-data-bank version 1 object')
    if not isinstance(bank.get('entries'),list): raise ValueError('entries must be a list')
    ids=set()
    for e in bank['entries']:
        if not isinstance(e,dict): raise ValueError('Each entry must be an object')
        for key in ['id','title','kind','summary']:
            if not isinstance(e.get(key),str) or (key!='summary' and not e[key]): raise ValueError('Entry needs text '+key)
        if e['id'] in ids: raise ValueError('Duplicate entry ID: '+e['id'])
        ids.add(e['id'])
        if 'tags' in e and (not isinstance(e['tags'],list) or not all(isinstance(t,str) and t and '\n' not in t and '\r' not in t for t in e['tags'])):
            raise ValueError('tags must be a list of nonempty single-line strings')
        deps=e.get('dependencies')
        if not isinstance(deps,dict) or not all(isinstance(deps.get(k),list) and all(isinstance(x,str) for x in deps[k]) for k in ['included','external','unresolved']):
            raise ValueError('dependencies needs included, external and unresolved string lists')
        if not isinstance(e.get('components'),list) or not e['components']: raise ValueError('Entry needs components')
        for c in e['components']:
            if not isinstance(c,dict) or 'payload' not in c or not isinstance(c.get('kind'),str): raise ValueError('Component needs kind and payload')
            if 'sourcePath' in c: tokens(c['sourcePath'])
    for e in bank['entries']:
        missing=set(e['dependencies']['included'])-ids
        if missing: raise ValueError('Missing included entry dependency: '+', '.join(sorted(missing)))
    return bank

def line(value): return str(value).replace('\n',' ').replace('\r',' ')

def render(bank):
    validate(bank)
    parts=['# IW Data Bank\n\nReadable index only; the JSON section is authoritative. Edit through unpack/pack to update the integrity hash.\n']
    for e in bank['entries']:
        parts.append('\n## '+line(e['title'])+'\nID: '+line(e['id'])+' | Kind: '+line(e['kind'])+'\n')
        if e.get('tags'): parts.append('Tags: '+' '.join('['+line(t)+']' for t in e['tags'])+'\n')
        if e['summary']: parts.append(line(e['summary'])+'\n')
        parts.append('Components: '+str(len(e['components']))+'\n')
    parts.extend(['\n',BEGIN,'\n```json\n',dumps(bank),'\n```\n',END,'\nSHA256: ',digest(bank),'\n'])
    return ''.join(parts)

def read_bank(path):
    text=Path(path).read_text(encoding='utf-8-sig')
    if text.lstrip().startswith('{'): return validate(loads(text))
    pattern=re.compile(r'^'+re.escape(BEGIN)+r'\r?\n```json\r?\n([\s\S]*?)\r?\n```\r?\n'+re.escape(END)+r'\r?\nSHA256: ([a-f0-9]{64}|UNVERIFIED)\s*\Z',re.M)
    matches=list(pattern.finditer(text))
    if len(matches)!=1 or len(re.findall(r'^'+re.escape(BEGIN)+r'\s*$',text,re.M))!=1:
        raise ValueError('Expected one complete Data bank section and SHA256 line')
    bank=validate(loads(matches[0][1]))
    if matches[0][2]!='UNVERIFIED' and digest(bank)!=matches[0][2]: raise ValueError('Integrity hash mismatch. Use the last intact copy or review the edit before repacking the authoritative JSON.')
    return bank

def export(doc,select=None,tags=None,bundle=None):
    if not isinstance(doc,dict): raise ValueError('World must be a JSON object')
    paths=[];layout=[]
    if select:
        if len(select)!=len(set(select)): raise ValueError('Selection repeats a path')
        decoded=[tokens(p) for p in select]
        for i,a in enumerate(decoded):
            for b in decoded[i+1:]:
                if a==b[:len(a)] or b==a[:len(b)]: raise ValueError('Selections overlap; choose parent or child, not both')
        paths=list(select)
    else:
        for k,v in doc.items():
            separate=k in COLLECTIONS and isinstance(v,list) and bool(v)
            layout.append({'key':k,'items':len(v) if separate else None})
            paths.extend('/'+escape(k)+'/'+str(i) for i in range(len(v))) if separate else paths.append('/'+escape(k))
    entries=[]
    for p in paths:
        payload=get(doc,p);key=tokens(p)[0]
        kind=COLLECTIONS.get(key,'world-field') if len(tokens(p))==2 else 'world-field'
        title=(payload.get('name') or payload.get('title') or payload.get('characterName')) if isinstance(payload,dict) else None
        entry={'id':'entry-'+uuid.uuid4().hex[:12],'title':str(title or p),'kind':kind,'summary':'',
               'dependencies':{'included':[],'external':[],'unresolved':['Dependency review required before reuse; extraction does not infer prose or dynamic references.']},
               'components':[{'kind':kind,'sourcePath':p,'payload':payload}]}
        if tags: entry['tags']=list(tags)
        entries.append(entry)
    if bundle and entries:
        first=entries[0];first['title']=bundle;first['kind']='bundle'
        first['components']=[c for e in entries for c in e['components']];entries=[first]
    bank={'format':FORMAT,'version':1,'source':{'title':str(doc.get('title','')),'sha256':digest(doc)},'entries':entries}
    if not select: bank['completeWorld']={'layout':layout}
    return validate(bank)

def restore(bank):
    validate(bank)
    layout=bank.get('completeWorld',{}).get('layout')
    if not isinstance(layout,list): raise ValueError('Only a complete-world report can be restored; selected entries require deliberate integration')
    components={}
    for e in bank['entries']:
        for c in e['components']:
            p=c.get('sourcePath')
            if p is None or p in components: raise ValueError('Missing or duplicate sourcePath')
            components[p]=c['payload']
    doc={};used=set()
    for item in layout:
        key=item['key'];n=item['items'];p='/'+escape(key)
        if key in doc: raise ValueError('Duplicate layout key')
        if n is None: doc[key]=components[p];used.add(p)
        else:
            if type(n) is not int or not 0<=n<=len(components): raise ValueError('Invalid layout length')
            paths=[p+'/'+str(i) for i in range(n)]
            doc[key]=[components[x] for x in paths];used.update(paths)
    if used!=set(components): raise ValueError('Extra components not described by the complete-world layout')
    if digest(doc)!=bank.get('source',{}).get('sha256'): raise ValueError('Restored world differs from the source fingerprint; review and integrate changed data deliberately')
    return doc

def write(path,text):
    # Never silently overwrite an existing bank/world.
    with Path(path).open('x',encoding='utf-8',newline='') as f: f.write(text)

def main():
    parser=argparse.ArgumentParser(description=__doc__)

"""Loss-aware read-only comparison of source and native re-exported worlds.
Usage: python tools/import_audit.py SOURCE.json IMPORTED.json
Reports differences and possible reminting, never rewrites either input.
"""
from pathlib import Path

def audit_import(before, after):
    def rows(w): return [x for x in w.get('trackedItems',[]) if isinstance(x,dict)]
    old,new=rows(before),rows(after)
    old_ids={x.get('id') for x in old if isinstance(x.get('id'),str)}
    new_ids={x.get('id') for x in new if isinstance(x.get('id'),str)}
    changes=[]
    for x in old:
        if x.get('id') in new_ids: continue
        candidates=[y for y in new if isinstance(x.get('name'),str) and x['name'] and isinstance(x.get('variableName'),str) and x['variableName'] and y.get('id') not in old_ids and y.get('name')==x.get('name') and y.get('variableName')==x.get('variableName')]
        changes.append({'objectName':x.get('name'),'variableName':x.get('variableName'),'oldId':x.get('id'),'status':'possible-remint' if len(candidates)==1 else 'removed-or-ambiguous','candidateIds':[y.get('id') for y in candidates]})
    dangling=[]
    def scan(value,path=''):
        if isinstance(value,dict):
            for k,v in value.items():
                q=path+'/'+str(k).replace('~','~0').replace('/','~1')
                is_pc=k=='id' and '/initialTrackedItemValues/' in q
                if (k in ('trackedItemID','targetTrackedItemId') or is_pc) and isinstance(v,str) and v in old_ids-new_ids:
                    names=[x.get('name') for x in old if x.get('id')==v]
                    dangling.append({'path':q,'targetNames':names,'oldId':v})
                scan(v,q)
        elif isinstance(value,list):
            for i,v in enumerate(value):scan(v,path+'/'+str(i))
    scan(after)
    return {'trackerIdentityChanges':changes,'referencesToRemovedTrackers':dangling,'diff':edit_diff(before,after),'note':'Possible reminting is a name/handle-based candidate, not an automatic identity decision. Positional changes and omissions are preserved in diff; no repair performed.'}

"""Lossless, review-gated IW story extraction and same-branch merge (standard library).

plan SOURCE --world WORLD --session NAME --branch NAME > plan.json
build PLAN... --output NEW_DIRECTORY [--partial]

Plans propose line boundaries; mark reviewed=true only after reviewing them.
Native text has unescaped delimiters, so inferred boundaries are not authoritative.
Build validates hashes and explicit spans, rejects conflicts, and writes a fresh
atomic output directory. It never overwrites a prior extraction or source file.
"""
from pathlib import Path
import argparse,hashlib,json,os,re,shutil,tempfile

HEADINGS={'Action':'action','Outcome':'outcome','Secret Information':'secretInfo','Tracked Items':'trackedItems','Hidden Tracked Items':'hiddenTrackedItems'}
ORDER={v:i for i,v in enumerate(HEADINGS.values())}
MARKER=re.compile(r'^-- Turn ([1-9][0-9]*) --$')

def digest(data):return hashlib.sha256(data).hexdigest()
def load_source(path):
    raw=Path(path).read_bytes()
    text=raw.decode('utf-8-sig')
    lines=text.replace('\r\n','\n').replace('\r','\n').split('\n')
    if lines and lines[-1]=='':lines.pop()
    return raw,lines
def text_span(lines,start,end):return '\n'.join(lines[start-1:end])
def check_span(start,end,low,high):
    if type(start)!=int or type(end)!=int or not low<=start<=end<=high:
        raise ValueError('Invalid or out-of-range line span')

def propose(path,names,session,branch):
    if not session or not branch:raise ValueError('Explicit session and branch are required')
    if len(set(names))!=len(names):raise ValueError('Duplicate tracker Names require manually resolved boundaries')
    raw,lines=load_source(path)
    markers=[(i+1,int(m[1])) for i,line in enumerate(lines) if (m:=MARKER.fullmatch(line))]
    if not markers:raise ValueError('No turn markers found')
    turns=[];issues=[]
    for idx,(start,number) in enumerate(markers):
        end=markers[idx+1][0]-1 if idx+1<len(markers) else len(lines)
        hits=[(i+1,HEADINGS[lines[i]]) for i in range(start,end-1) if lines[i] in HEADINGS and re.fullmatch('-{4,}',lines[i+1])]
        sections=[]
        for j,(header,kind) in enumerate(hits):
            stop=hits[j+1][0]-1 if j+1<len(hits) else end
            sec={'kind':kind,'headerLine':header,'endLine':stop}
            if kind in ('trackedItems','hiddenTrackedItems'):
                found=[(k+1,lines[k][:-1]) for k in range(header+1,stop) if lines[k].endswith(':') and lines[k][:-1] in names]
                sec['trackers']=[{'name':name,'startLine':pos,'endLine':found[n+1][0]-1 if n+1<len(found) else stop} for n,(pos,name) in enumerate(found)]
                if len({name for _,name in found})!=len(found):issues.append('Duplicate possible tracker header at turn '+str(number))
                if not found and any(x.strip() for x in lines[header+1:stop]):issues.append('Unresolved tracker section at turn '+str(number))
            sections.append(sec)
        kinds=[s['kind'] for s in sections]
        if kinds!=sorted(set(kinds),key=lambda k:ORDER[k]) or 'outcome' not in kinds:issues.append('Ambiguous/missing section boundaries at turn '+str(number))
        turns.append({'number':number,'startLine':start,'endLine':end,'sections':sections})
    nums=[t['number'] for t in turns]
    if nums!=list(range(nums[0],nums[0]+len(nums))):issues.append('Nonconsecutive or duplicate proposed turn markers')
    return {'version':1,'session':session,'branch':branch,'reviewed':False,'path':str(Path(path).resolve()),'sha256':digest(raw),'trackerNames':list(names),'turns':turns,'reviewIssues':issues,'boundaryNotice':'Unescaped text can imitate turn, section or tracker headings. Review and correct spans; reviewed=true is an operator assertion, not inferred certainty.'}

def extract(plan):
    if plan.get('reviewed') is not True:raise ValueError('Review line boundaries and set reviewed=true before extraction')
    if not isinstance(plan.get('session'),str) or not plan['session'].strip() or not isinstance(plan.get('branch'),str) or not plan['branch'].strip():raise ValueError('Explicit nonempty session and branch required')
    if plan.get('reviewIssues'):raise ValueError('Resolve reviewIssues and clear them after reviewing the layout')
    raw,lines=load_source(plan['path'])
    if digest(raw)!=plan.get('sha256'):raise ValueError('Source SHA256 mismatch; regenerate/review plan')
    turns=plan.get('turns',[])
    if not isinstance(turns,list) or not turns:raise ValueError('Plan needs explicit turn spans')
    parsed=[];last_end=None;last_num=None
    names=plan.get('trackerNames',[])
    if not isinstance(names,list) or not all(isinstance(n,str) and n for n in names) or len(names)!=len(set(names)):raise ValueError('Tracker Names must be unique nonempty strings')
    for turn in turns:
        n=turn['number'];start=turn['startLine'];end=turn['endLine']
        check_span(start,end,1,len(lines))
        if type(n)!=int or n<1 or lines[start-1]!=f'-- Turn {n} --':raise ValueError('Turn marker does not match approved span')
        if last_end is not None and (start!=last_end+1 or n!=last_num+1):raise ValueError('Turn spans must be contiguous and sequential within a source')
        last_end,last_num=end,n
        sections=turn['sections'];kinds=[s['kind'] for s in sections]
        if 'outcome' not in kinds or any(k not in ORDER for k in kinds) or kinds!=sorted(set(kinds),key=lambda k:ORDER[k]):raise ValueError('Invalid/duplicate section sequence')
        data={'number':n,'sections':{},'trackedItems':{},'hiddenTrackedItems':{}}
        prev=start
        for idx,sec in enumerate(sections):
            h,e=sec['headerLine'],sec['endLine'];check_span(h,e,start+1,end)
            expected_end=sections[idx+1]['headerLine']-1 if idx+1<len(sections) else end
            if h<=prev or e!=expected_end:raise ValueError('Overlapping or incomplete section spans')
            if idx==0 and any(x.strip() for x in lines[start:h-1]):raise ValueError('Unclassified text before first section')
            label=next(k for k,v in HEADINGS.items() if v==sec['kind'])
            if lines[h-1]!=label or h>=e or not re.fullmatch('-{4,}',lines[h]):raise ValueError('Section header does not match approved span')
            prev=e
            body=text_span(lines,h+2,e) if h+2<=e else ''
            data['sections'][sec['kind']]=body
            if sec['kind'] in ('trackedItems','hiddenTrackedItems'):
                ts=sec.get('trackers',[]);previous=h+1
                for j,item in enumerate(ts):
                    a,b=item['startLine'],item['endLine'];name=item['name'];check_span(a,b,h+2,e)
                    boundary=ts[j+1]['startLine']-1 if j+1<len(ts) else e
                    if a<=previous or b!=boundary or name not in names or lines[a-1]!=name+':' or name in data[sec['kind']]:raise ValueError('Invalid/duplicate tracker boundary')
                    if j==0 and any(x.strip() for x in lines[h+1:a-1]):raise ValueError('Unclassified tracker text before first Name')
                    data[sec['kind']][name]=text_span(lines,a+1,b) if a<b else ''
                    previous=b
                if not ts and body.strip():raise ValueError('Unresolved tracker section; provide reviewed Name boundaries')
        if set(data['trackedItems']) & set(data['hiddenTrackedItems']):raise ValueError('Same tracker Name in visible and hidden sections is ambiguous')
        data['content']=text_span(lines,start,end).rstrip('\n')
        data['contentSha256']=digest(data['content'].encode('utf8'))
        data['provenance']=[{'sourceSha256':digest(raw),'path':str(Path(plan['path']).resolve()),'lineRange':[start,end]}]
        parsed.append(data)
    if last_end!=len(lines):raise ValueError('Unclassified text after final turn span')
    return parsed

def merge(plans,partial=False):
    if not plans:raise ValueError('No sources')
    identity={(p.get('session'),p.get('branch')) for p in plans}
    if len(identity)!=1:raise ValueError('Different sessions/branches cannot be merged; select a branch explicitly')
    merged={}
    for plan in plans:
        for turn in extract(plan):
            n=turn['number']
            if n in merged:
                old=merged[n]
                # Identical text is insufficient if operators approved different parsing.
                if any(old[k]!=turn[k] for k in ('content','sections','trackedItems','hiddenTrackedItems')):raise ValueError(f'Conflicting turn {n}; choose/reconcile a branch before merging. No timestamp winner.')
                old['provenance'].extend(turn['provenance'])
            else:merged[n]=turn
    nums=sorted(merged)
    if nums!=list(range(nums[0],nums[-1]+1)) or (not partial and nums[0]!=1):raise ValueError('History has gaps or missing initial turns; partial only permits a contiguous later range')
    for t in merged.values():t['provenance']=sorted({json.dumps(p,sort_keys=True):p for p in t['provenance']}.values(),key=lambda p:(p['sourceSha256'],p['lineRange'],p['path']))
    session,branch=next(iter(identity))
    return {'session':session,'branch':branch,'partial':bool(partial),'boundaryAssurance':'operator-reviewed; text format is unescaped','turns':[merged[n] for n in nums]}

def publish(plans,destination,partial=False):
    dest=Path(destination).resolve()
    if dest.exists():raise ValueError('Output must be a new directory; existing extractions are never overwritten')
    result=merge(plans,partial)
    if not dest.parent.is_dir():raise ValueError('Output parent must exist')
    stage=Path(tempfile.mkdtemp(prefix='.iw-story-',dir=dest.parent))
    # The only cleanup target is this tool-created sibling staging directory.
    assert stage.parent==dest.parent and stage.name.startswith('.iw-story-')
    try:
        src=stage/'sources';src.mkdir();records=[]
        for p in sorted(plans,key=lambda p:(p['sha256'],p['path'])):
            raw=Path(p['path']).read_bytes()
            if digest(raw)!=p['sha256']:raise ValueError('Source changed during publication')
            name='sources/'+p['sha256']+'.txt';(stage/name).write_bytes(raw)
        (stage/'reviewed-plans.json').write_text(json.dumps(plans,indent=2,ensure_ascii=False)+'\n',encoding='utf8')
        (stage/'story.json').write_text(json.dumps(result,indent=2,ensure_ascii=False)+'\n',encoding='utf8')
        for p in sorted(stage.rglob('*')):
            if p.is_file():records.append({'path':p.relative_to(stage).as_posix(),'sha256':digest(p.read_bytes())})
        manifest={'version':1,'session':result['session'],'branch':result['branch'],'partial':result['partial'],'files':records}

        if dest.exists():raise ValueError('Output appeared during publication')
        stage.rename(dest)
    finally:
        if stage.exists():shutil.rmtree(stage)
    return manifest

def fresh_dir(path):

    return path


def capture(page, out):
    """Publish complete evidence in a fresh directory; preserve previous captures."""
    out = out.resolve()
    if out.exists(): raise ValueError('Capture destination already exists')
    out.parent.mkdir(parents=True, exist_ok=True)
    stage = Path(tempfile.mkdtemp(prefix='.iw-capture-', dir=out.parent))
    try:
        (stage / 'page.txt').write_text(page.locator('body').inner_text(), encoding='utf8')
        (stage / 'accessibility.yaml').write_text(page.locator('body').aria_snapshot(), encoding='utf8')
        metadata = {'capturedAt': datetime.now(timezone.utc).isoformat(), 'url': page.url,
                    'title': page.title(), 'scope': 'Rendered panels only; neither saved-turn proof nor a full prompt/character database.'}
        (stage / 'capture.json').write_text(json.dumps(metadata, indent=2), encoding='utf8')
        records = [{'path': p.name, 'sha256': hashlib.sha256(p.read_bytes()).hexdigest()} for p in sorted(stage.iterdir())]
        (stage / 'manifest.json').write_text(json.dumps({'files': records}, indent=2), encoding='utf8')
        if out.exists(): raise ValueError('Capture destination appeared during capture')
        stage.rename(out)
    finally:
        # stage is allocated directly under the resolved output parent, never user input.
        if stage.exists():
            if stage.resolve().parent != out.parent or not stage.name.startswith('.iw-capture-'):
                raise ValueError('Refusing cleanup outside staging directory')
            shutil.rmtree(stage)
    return out


def world_boxes(page):
    found = []
    for box in page.locator('textarea').all():
        if not box.is_visible(): continue
        try:
            text = box.input_value(); value = json.loads(text)
        except (ValueError, TypeError): continue
        if isinstance(value, dict) and isinstance(value.get('title'), str) and 'schemaVersion' in value:
            found.append((box, text, value))
    return found


def export_current(page, out, expected_title, attempts=80):
    """Back up raw text, invalidate only that buffer, then require regenerated JSON.

    No import/save calls. The original buffer survives on disk even if disconnected.
    Close/reopen/import operations must have finished before using this command.
    """
    out = out.resolve(); backup = out.with_name(out.name + '.before.json')
    receipt = out.with_name(out.name + '.receipt.json')
    if any(p.exists() for p in (out, backup, receipt)): raise ValueError('Output, backup or receipt already exists')
    button = page.get_by_role('button', name='Refresh raw JSON', exact=True)
    if button.count()!=1 or not button.is_visible(): raise ValueError('Open the intended raw JSON panel first')
    found = world_boxes(page)
    if len(found)!=1: raise ValueError('Expected exactly one visible world JSON buffer')
    box, original, before = found[0]
    if before['title']!=expected_title: raise ValueError('Raw world title does not match --expected-title')
    out.parent.mkdir(parents=True, exist_ok=True)
    with backup.open('x', encoding='utf8', newline='') as f: f.write(original)
    sentinel = 'IW_REFRESH_PENDING_' + uuid.uuid4().hex
    changed = False
    try:
        box.fill(sentinel); changed = True
        if box.input_value()!=sentinel: raise ValueError('Could not establish refresh marker')
        button.click()
        for _ in range(attempts):
            page.wait_for_timeout(250)
            text = box.input_value()
            if text == sentinel: continue
            try: value = json.loads(text)
            except (ValueError, TypeError): continue
            if not isinstance(value,dict) or value.get('title')!=expected_title or 'schemaVersion' not in value:
                raise ValueError('Refreshed data does not match the intended world')
            found = world_boxes(page)
            if len(found)!=1 or found[0][1]!=text: raise ValueError('Ambiguous refreshed raw buffers')
            # Same content as original is legitimate: observing the marker replaced is the freshness evidence.
            with out.open('x',encoding='utf8',newline='') as f: f.write(text)
            with receipt.open('x',encoding='utf8') as f:
                json.dump({'capturedAt':datetime.now(timezone.utc).isoformat(),'title':expected_title,
                           'sha256':hashlib.sha256(out.read_bytes()).hexdigest(),
                           'freshness':'Observed replacement of a unique marker after Refresh raw JSON.',
                           'scope':'Editor regeneration only; not server persistence or live-state proof.',
                           'backup':backup.name},f,indent=2)
            return out
        raise ValueError('Refresh did not replace the marker within the deadline; no export published')
    finally:
        # Restore only our marker. Never overwrite a newer UI value or retry after disconnection.
        if changed:
            try:
                if box.input_value()==sentinel: box.fill(original)
            except Exception:
                pass  # The on-disk .before.json is the recovery source if detached/disconnected.

"""Compile a literal-Scenario prerequisite DAG into a new IW world. No runtime inference."""
from __future__ import annotations
import argparse,copy,hashlib,json,re
from pathlib import Path


def analyze(plan):
    if not isinstance(plan,dict) or not isinstance(plan.get('nodes'),list) or not plan['nodes']:
        raise ValueError('Plan needs a nonempty nodes list')
    if set(plan)-{'title','nodes'}:raise ValueError('Unknown plan field')
    if not isinstance(plan.get('title'),str) or not plan['title'].strip():raise ValueError('Plan needs a title')
    nodes=plan['nodes']; by={}
    for n in nodes:
        if not isinstance(n,dict) or set(n)-{'id','name','scenario','requires','award'}:raise ValueError('Unknown node field or invalid node')
        key=n.get('id')
        if not isinstance(key,str) or not re.fullmatch('[a-z][a-z0-9_]*',key):raise ValueError('Node id must be a lowercase identifier')
        if key == 'score':raise ValueError('score is reserved')
        if key in by:raise ValueError('Duplicate node id: '+key)
        if any(not isinstance(n.get(k),str) or not n[k].strip() for k in ('name','scenario')):raise ValueError('Each node needs Name and literal Scenario')
        if any(x in n['scenario'] for x in ('<<','<=','<#')):raise ValueError('Dynamic Scenarios are outside this compiler contract')
        deps=n.get('requires',[])
        if not isinstance(deps,list) or any(not isinstance(d,str) for d in deps) or len(set(deps))!=len(deps):raise ValueError('requires must contain unique node ids')
        award=n.get('award',0)
        if type(award)!=int or award<0:raise ValueError('award must be a nonnegative integer')
        by[key]=n
    for key,n in by.items():
        for d in n.get('requires',[]):
            if d not in by:raise ValueError('Unknown prerequisite '+d+' on '+key)
    pending=list(by);order=[]
    while pending:
        ready=[k for k in pending if all(d in order for d in by[k].get('requires',[]))]
        if not ready:raise ValueError('Cyclic prerequisites: '+', '.join(pending))
        order.extend(ready);pending=[k for k in pending if k not in ready]
    groups={}
    for n in nodes:groups.setdefault(n['scenario'],[]).append(n['name'])
    return {'order':order,'structurallyReachable':order,'roots':[k for k in order if not by[k].get('requires')],
            'sharedScenarios':{s:n for s,n in groups.items() if len(n)>1},
            'scope':'All-of prerequisite connectivity only. Scenario recognition, timing, character knowledge and narrative satisfiability are not proved. Shared Scenarios may complete several nodes in the same turn.'}


def identity(kind,key):return hashlib.sha256((kind+':'+key).encode()).hexdigest()[:18]


def compile_world(plan,template):
    report=analyze(plan);w=copy.deepcopy(template)
    # Always a fresh scaffold, never merge over an existing authored world.
    if template.get('trackedItems') or template.get('triggerEvents'):raise ValueError('Template must have no trackers or triggers')
    w.update(title=plan['title'],description='A literal-Scenario prerequisite graph.',background='A courier works through the objectives below.',
             instructions='Follow the declared objectives. Treat Plot progress as authoritative; do not invent rewards.',
             firstInput='Describe the opening situation and the available objectives.',mature=False,nsfw=False,
             conditions=list(dict.fromkeys(n['scenario'] for n in plan['nodes'])),trackedItems=[],triggerEvents=[])
    nodes={n['id']:n for n in plan['nodes']}
    initial='score: 0\n'+'\n'.join(k+': 0' for k in report['order'])
    # Reserve the score key so completion cannot alias the award total.
    if 'score' in nodes:raise ValueError('score is reserved')
    w['trackedItems']=[dict(id=identity('tracker','plot'),name='Plot progress',variableName='plot',positionInList=0,
         dataType='yaml',visibility='everyone',description='Completion flags and awarded score. Script-owned.',
         initialValue=initial,initialValueBasedOnPC='same',autoUpdate=False,updateInstructions='',enforceFormat=False)]
    for k in report['order']:
        n=nodes[k];guard=' and '.join(['$plot.'+k+' = 0']+['$plot.'+d+' = 1' for d in n.get('requires',[])])
        script='if '+guard+'\n    $plot.score += '+str(n.get('award',0))+'\n    $plot.'+k+' = 1'
        w['triggerEvents'].append(dict(id=identity('trigger',k),name=n['name'],advancedLogic=False,
            triggerOnStartOfGame=False,triggerMidGame=False,canTriggerMoreThanOnce=True,
            triggerConditions=[dict(id=identity('event',k),category='condition',type='triggerOnEvent',data=n['scenario']),
                               dict(id=identity('guard',k),category='condition',type='triggerOnPawScript',data=guard)],
            triggerEffects=[dict(id=identity('commit',k),type='effectRunScript',data=script)]))
    report['triggerOrder']=[nodes[k]['name'] for k in report['order']]
    return w,report


def main():
    p=argparse.ArgumentParser(description=__doc__);p.add_argument('plan',type=Path);p.add_argument('--output',type=Path)
    a=p.parse_args()
    try:
        plan=json.loads(a.plan.read_text(encoding='utf-8-sig'))
        template=json.loads((Path(__file__).resolve().parent.parent/'World-Template.json').read_text(encoding='utf8'))
        w,r=compile_world(plan,template)
        if a.output:
            from validate_iw_export import validate
            schema=json.loads(Path(__file__).with_name('iw-export.schema.json').read_text(encoding='utf8'))
            findings=validate(w,schema)
            if any(f['severity']=='error' for f in findings):raise ValueError(json.dumps(findings))
            with a.output.open('x',encoding='utf8') as f:json.dump(w,f,ensure_ascii=False,indent=2)
            r['validation']=findings
        print(json.dumps(r,indent=2,ensure_ascii=False))
    except (ValueError,OSError,KeyError,TypeError) as e:p.exit(2,str(e)+'\n')
if __name__=='__main__':main()
