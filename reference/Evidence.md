# Compatibility and evidence

This is an independent, unaffiliated kit. Platform baseline: Infinite Worlds' October 8, 2026 "Save/load system, Image style system and Pawscript update," with editor/runtime information consolidated through October 24, 2026. Export schemaVersion is 2.4. Kit version is 1.5.0; the structural profile is 1.2.0. Neither is an IW application version. The unaffiliated Script Library source snapshot is version 3.16, October 16, 2026; source details and updating advice are in ../library/Integration.md.

Use four evidence labels when a distinction matters. Ordinary reference sentences do not need a repeated tag.

| Label | Meaning |
| --- | --- |
| [DOCUMENTED] | Supported by editor help, a native export shape or cited language documentation. Does not alone establish runtime behavior. |
| [RUNTIME] | The stated behavior was exercised in IW within the described scope. Does not certify every composition or variant. |
| [PATTERN] | An optional authoring design assembled from supported features; not a platform requirement. |
| [UNKNOWN] | A concrete behavior remains unresolved; avoid depending on it without a focused check. |

Structural validation is a separate status, not a fifth evidence label. It checks export structure and explicit references. Static lint reports likely mistakes; neither executes PawScript or certifies a story. The example index records structural and runtime scope separately. Known-Limits.md lists open boundaries without development history. Do not present generated prose as evidence of tracker state.

## Engineering scope

Profile 1.2.0 incorporates observed native turn thresholds and startup effect shapes without claiming hidden character mutation. Current tools include a read-only import audit and a source-preserving story extractor with reviewed boundaries and explicit same-branch conflict rejection. These are local engineering capabilities, not additional platform observations or a certification of the unchanged external parser.
