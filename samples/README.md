# From an idea to a playable world

Curious what making a world with the kit actually looks like? These projects pair the finished world with the conversation that shaped it. Browse the back-and-forth to see how an idea develops, what the AI asks, and how the author steers the result.

| Shard of the Loom | [Read the conversation](https://iw-builder.github.io/samples/shard-of-the-loom/) | [Download JSON](Gemini%204%20Argon%20-%20Shard%20of%20the%20Loom.json) |
| Bad Touch | [Read the conversation](https://iw-builder.github.io/samples/bad-touch/) | [Download JSON](MiMo%202.6%20Pro%20-%20Bad%20Touch.json) |

The conversations are long and may include mature content. You can skim them for inspiration; they are not tutorials you need to finish or rules for how your own world should work. The Markdown files contain the conversations, and the matching JSON files can be imported into IW.
