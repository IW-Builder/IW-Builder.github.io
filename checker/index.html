    What this page does
    • Accepts the raw model reply: strips ``` fences, removes chat text before and after the JSON, drops any trailing newline.
    • Assembles numbered chunks ("Chunk 1/3", "Chunk 1 of 3", "Part 2/4" and similar) into one document, checking that every chunk is present exactly once.
    • If several JSON objects are pasted at once, it validates the largest one and tells you it did so.
    • Runs a verbatim embedded copy of the kit's validator (tools/validate_iw_export.py, tools/static_checks.py and tools/iw-export.schema.json) in Python-in-the-browser (Pyodide): full JSON Schema structure checks when the jsonschema package loads, reference and ID checks, and the static lint (unknown script roots, borrowed syntax, string + concatenation, unfilled library placeholders).
    • Nothing is executed: PawScript, expressions and templates are checked as text only. A clean result does not certify import or gameplay.
    • "Copy report for your AI" formats the findings to paste back into the chat; "Copy for IW" gives clean JSON that ends exactly at the final closing brace.

    Self-contained and private: the validator and schema are embedded in this file. The only network traffic is the one-time download of the Python runtime (and the jsonschema wheel, when available) from cdn.jsdelivr.net — after that, checks work even offline if the browser has them cached. The world you paste is processed entirely on your device, and this file can be saved and re-opened locally.

    Warnings are review notes, not automatic defects — see tools/README.md in the kit for each diagnostic code.
