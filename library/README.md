# Sample Library

Reusable instruction blocks and components for IW worlds, including Storymaster, time/location formatting and tracker systems.

Read [Integration.md](Integration.md) for selection guidance, dependencies, customization and approximate token costs. [Sample-Blocks.json](Sample-Blocks.json) contains the source components; select and adapt relevant portions rather than including everything.

Source material comes from the unaffiliated **The Script Library**, version 3.16, updated October 16, 2026. The [original world](https://infiniteworlds.app/shared/Dxb2ko) includes additional content and is frequently updated.

[Main guide](https://iw-builder.github.io/guide/)
