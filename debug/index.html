IW Debug Exporter

The debug counterpart of Export story. For every turn of the game you have open, it saves what World debug tools shows: the evaluation, thinking (on models that think), triggers fired, active instruction blocks, matched lore, PawScript results and errors, and the long term memory the storyteller used. You get a readable text file and a JSON file.

Install

Drag this button onto your browser's bookmarks bar:

IW Debug Export

Bookmarks bar hidden? Press Ctrl+Shift+B (Cmd+Shift+B on Mac) to show it. Clicking the button here does nothing; it only works from your bookmarks on the Infinite Worlds site.

Can't drag it? Add it by hand

Copy the code, create a new bookmark named "IW Debug Export", and paste the code into its URL or address field.

Use

  1. Open infiniteworlds.app, sign in, and open or load the game. Wait until no turn is generating.
  2. Click the IW Debug Export bookmark. A status box appears in the bottom-right corner.
  3. It waits up to 30 seconds for the site's next keep-alive message, then steps through the game one turn at a time. Each turn takes a few seconds, sometimes more when IW is busy.
  4. When it says Done, two files download, and the game is back on the turn you were viewing.

What you get

.txtOne section per turn: the action, evaluation, thinking, triggers fired, active instruction blocks (rendered text, printed in full only when a block changed since the previous turn), lore matched, every PawScript condition and effect with its status, the error count, and the long term memory (printed in full when it changes: story, current situation, key moments, characters, plot threads, secrets, lore, future notes). .jsonThe same per turn, plus each script result's error field and IW's raw per-turn debug fields and the long term memory as IW sends it (in full on the turn it changes, a pointer to that turn otherwise). World-wide definitions (trigger names, main instructions, lore keywords) appear once at the top.

It reads the same data the Previous turn and Next turn buttons load, over the connection the site already has open. It takes no game actions and sends nothing anywhere else.

Narration, Secret Info and tracker values aren't repeated here; use IW's own Export story for those. Don't take a turn while the exporter is running. Stop and save stops early and downloads what it has. If it can't put you back on your turn, it says so; reload the page before you play on.
